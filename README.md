# Wayback Context Menu

Расширение для Chrome, добавляющее пункт "Wayback Machine" в контекстное меню.

## Возможности и использование

- **На странице** — клик правой кнопкой на любой странице → "Wayback Machine"
- **На ссылке** — клик правой кнопкой на ссылке → "Wayback Machine"
- **Выделенный текст** — выделите URL, правая кнопка → "Wayback Machine"

При выборе пункта меню открывается страница `web.archive.org` с историей выбранного URL.

## Установка

1. Скачайте репозиторий
2. Откройте `chrome://extensions/`
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованную"
5. Выберите папку с расширением
